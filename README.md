# trabalho teste de Software: Microserviço de Autenticação Social (Oauth)

Serviço FastAPI que simula o login via OAuth2 com Google/GitHub e realiza o cadastro de usuários localmente.

# Como Executar
Instale as dependências necessárias:
terminal
    "pip install fastapi uvicorn pytest httpx"

# Execute o servidor local
terminal
   "uvicorn main:app --reload"
